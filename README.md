# UI-UX-Experiment3

## Aim:
To design an attractive and user-friendly food ordering website UI with food categories, search options, and login features.

## Algorithm:
1.Start the application.

2.Design the home page with two main sections.

3.In the left section, display a food image with a welcome message.

4.Add a Get Started button for new users.

5.Provide login and password fields for existing users.

6.Add a Sign In button to access the application.

7.In the right section, display the application name as Maan Food.

8.Add a location icon to display the location.

9.Create a search bar to search for food items.

10.Display food categories such as Burger, Pizza, and Chicken with images.

11.Add a special offer banner to attract customers.

12.Complete the UI design with suitable colors, fonts, and images.

13.Stop the application.
